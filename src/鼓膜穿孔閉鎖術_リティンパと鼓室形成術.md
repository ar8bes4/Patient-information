# 🏥 鼓膜穿孔の閉鎖治療についてのご説明
### — リティンパ（鼓膜再生療法）と鼓室形成術、および二次性真珠腫について —

この説明書は、鼓膜に穴（穿孔）があり、その閉鎖治療を検討されている患者さんとご家族に対し、病態・主な治療法の選択肢（**リティンパ**と**鼓室形成術**）、および治療に伴うリスク（**二次性真珠腫**など）と術後経過観察の重要性についてご説明するためのものです。

---

## 1. 鼓膜穿孔（鼓膜の穴）と治療の必要性

### ① 鼓膜穿孔とは
鼓膜は、外耳道（耳の穴）と中耳（鼓膜の奥の小空間）を隔てる薄い膜です。過去の慢性中耳炎や、耳のケガ（外傷）、中耳へのチューブ留置後などにより、鼓膜に穴が開いたまま閉じなくなることがあります。

### ② 穴を放置することによるリスク
鼓膜に穴が開いていると、主に以下のような問題が生じます。
* **聞こえにくさ（伝音難聴）**: 音の振動が中耳へ効率よく伝わらなくなり、耳が詰まった感じや難聴が生じます。
* **繰り返す耳漏（耳だれ）・感染**: お風呂やプールで水が入ったり、風邪を引いた際に、穴を通じて中耳に細菌が侵入しやすくなり、手遅れになると周囲の骨や耳小骨に炎症が広がります。

## 2. 鼓膜を閉じる2つの治療法

鼓膜の穴を塞ぐ方法には、主にお身体への負担が少ない**「リティンパによる鼓膜再生療法」**と、手術室で確実に形を作る**「鼓室形成術 / 鼓膜形成術」**があります。穿孔の大きさや中耳の状態に応じて最適な方法を選択します。

### 治療法 A：リティンパを用いた鼓膜再生療法（外来・日帰り処置）

**【仕組み】**
鼓膜には本来、傷を自ら修復する能力があります。リティンパは、創傷治癒（組織の再生）を促すタンパク質（トラフェルミン / bFGF）を含んだ特殊なスポンジ状の基材です。
1. 局所麻酔の後、穴の縁（ふち）の硬くなった粘膜をわずかに削り（トリミング / 新鮮化）、再生のきっかけを作ります。
2. 穴の大きさに合わせてカットした「リティンパ」を穴に挟み込むように留置します。
3. リティンパが足場となり、ご自身の鼓膜組織が徐々に伸びて穴が塞がっていきます（基材は徐々に吸収・置換されます）。

* **メリット**: 
  - 外来処置室で15〜30分程度で行え、**日帰り**が可能です。
  - 全身麻酔や皮膚切開が不要で、**身体への負担が極めて少ない**です。
* **適応と限界**:
  - 小さめ〜中くらいの大きさの穿孔に適しています。
  - 中耳の奥の粘膜に強い炎症や感染がある場合、または音を伝える骨（耳小骨）に壊死や固着などの異常がある場合は、成功率が低下するため適さないことがあります。

> {{slide_summary: リティンパは外来で短時間にできる低侵襲治療です。ご自身の鼓膜再生力を高めて穴を塞ぎます。}}
> {{visual: retynpa-procedure-concept}}

### 治療法 B：鼓室形成術 / 鼓膜形成術（手術室での再建手術）

**【仕組み】**
患者さんご自身の身体の一部（耳の周囲の筋膜〈側頭筋膜〉や、耳の軟骨・軟骨膜など）を移植片（グラフト）として採取し、鼓膜の穴を塞ぐ裏打ちや補強を行う手術です。
1. 局所麻酔または全身麻酔下で、耳の穴の中または耳の後ろの皮膚をわずかに切開します。
2. 中耳の病変（炎症性組織や真珠腫など）を掃除し、必要に応じて音を伝える骨（耳小骨）の連鎖を再建します（**鼓室形成術**）。
3. 採取した筋膜や軟骨を鼓膜の穴に当てて固定し、新たな鼓膜の土台を作ります。

* **メリット**:
  - 大きな穿孔や、長年の炎症で鼓膜が著しく薄くなっている場合でも、高い確率で閉鎖できます。
  - 耳小骨の異常や中耳病変がある場合、同時に根本的な治療と聴力改善（鼓室形成）が可能です。
* **注意点**:
  - 手術室での施行となり、日帰り〜数日間の入院が必要です。
  - 傷口の治癒や鼓膜の安定までに一定の期間がかかります。

> {{slide_summary: 鼓室形成術は、ご自身の筋膜や軟骨を移植する確実性の高い手術です。中耳病変の同時治療が可能です。}}
> {{visual: tympanoplasty-graft-concept}}

---

### ⚖️ 治療法の比較一覧

| 比較項目 | リティンパ（鼓膜再生療法） | 鼓室形成術 / 鼓膜形成術 |
| :--- | :--- | :--- |
| **治療場所** | 処置室（外来） | 手術室（日帰り 〜 入院） |
| **麻酔方法** | 局所麻酔（耳の麻酔のみ） | 局所麻酔 または 全身麻酔 |
| **身体への侵襲** | **非常に小さい**（切開なし） | 中等度（皮膚切開・組織採取あり） |
| **使用する材料** | 医療用再生基材（リティンパ） | ご自身の筋膜・軟骨（自己組織） |
| **主な適応** | 小〜中規模の穿孔（中耳病変なし） | 大規模な穿孔・中耳病変/耳小骨異常あり |
| **中耳病変の治療** | できません（中耳が健全なことが条件） | **同時に清掃・再建が可能** |

## 3. 重要なリスク：二次性真珠腫（医原性真珠腫）について

鼓膜の穿孔閉鎖治療を受けるにあたり、ぜひご理解いただきたい重要な合併症・後遺症の一つに**「二次性真珠腫（医原性真珠腫）」**があります。

### ① 二次性真珠腫とは
真珠腫（しんじゅしゅ）とは、腫瘍（がん）ではなく、**耳の皮膚の表皮（上皮）組織が中耳の奥に入り込み、角質（垢）が塊となって真珠状に溜まっていく病態**です。溜まった真珠腫は徐々に大きくなり、周囲の骨や耳小骨を溶かす性質があります。

### ② なぜ発生するのか（メカニズム）
鼓膜の穿孔閉鎖処置（リティンパの留置、または鼓室形成術での筋膜移植）を行う際、以下のような理由で生じることがあります。
1. **上皮成分の閉じ込め**: 穿孔の縁をトリミングする際や筋膜を敷き込む際、目に見えないほどごく微細な皮膚の上皮細胞が中耳側に残ったまま穴が閉じると、閉ざされた空間の中で上皮が増殖して真珠腫になります。
2. **鼓膜の凹み（陥凹）**: 閉鎖後の鼓膜が圧の変化などにより内側に深く引き込まれ、ポケット状に凹んで角質が溜まることで二次的に真珠腫へ変化することがあります。

### ③ 予防と早期発見（定期通院の絶対的理由）
二次性真珠腫の発生頻度は**極めて稀（数％以下）**ですが、放置すると聴力低下やめまい、耳漏の原因となるため、見逃してはならない病態です。

> [!IMPORTANT]
> **閉鎖後も定期的な経過観察が必須です。**
> 鼓膜の穴が綺麗に塞がった後も、医師の指示に従って**定期的な耳内視鏡診察や画像検査（CT・MRI）**をお受けください。
> 万が一、二次性真珠腫が形成された場合でも、早期に発見できれば外来での処置や小さな追加手術で安全に摘出・治療が可能です。

> {{slide_summary: 鼓膜閉鎖後、ごく稀に上皮が閉じ込められて二次性真珠腫が生じることがあります。早期発見のため定期通院が不可欠です。}}
> {{visual: secondary-cholesteatoma-mechanism}}

## 4. 術後の注意点とセルフケア

治療を受けた後は、鼓膜が安定して生着するまで以下の点にご注意ください。

1. **耳に水や異物を入れない**
   - 処置・手術後は、医師の許可が出るまで洗髪やシャワー時に耳栓を使用し、水が入らないようにしてください。
2. **強く鼻をかまない**
   - 鼻を強くかむと、中耳への圧力（耳管経由）が高まり、再生中の鼓膜や移植した筋膜が飛ばされたり位置がずれたりする危険があります。鼻水はすする程度にするか、優しく押さえてください。
3. **指示された耳科用点耳薬・内服薬の使用**
   - 感染予防や炎症抑制のため、処方されたお薬は医師の指示通り使用してください。
4. **定期受診の継続**
   - 穴が塞がった後も、二次性真珠腫の発生チェックや鼓膜の厚みの変化を確認するため、指定された受診日には必ずご来院ください。

## 5. 担当医とのご相談・同意について

治療法の選択にあたっては、マイクロスコープや内視鏡による鼓膜観察、聴力検査、CT検査等の結果を踏まえ、患者さんの生活スタイルやご希望に合わせて最適な方法をご提案いたします。

疑問点やご不安な点がございましたら、遠慮なく担当医にご質問・ご相談ください。
