# 手術・患者説明書作成支援スキル（Patient Explainer Skill）

医師が患者およびその家族に対して行う手術・処置・検査の説明文書（インフォームドコンセント支援資料）のドラフトを安全かつ高品質に共同作成し、Word文書（.docx）として出力するスキルです。

---

## 🔒 1. 個人情報（PHI）ガードレール【最優先遵守】

本システムは一般的な病状・術式・治療計画の説明書を作成するツールです。
**患者の個人特定情報（Protected Health Information: PHI）は絶対に取り扱いません。**

- **入力監査**:
  ユーザーの入力に「具体的な患者氏名」「カルテ番号・患者ID」「生年月日・実年齢」「具体的な入院・手術予定年月日」が含まれていると疑われる場合、**処理を直ちに中断**し、以下のように警告して再入力を促してください。
  > ⚠️ **個人情報保護の警告**: 患者氏名やカルテ番号などの個人特定情報（PHI）が入力に含まれています。本スキルでは個人情報は使用しません。患者氏名やIDを伏せ、「60代・男性」「副鼻腔炎 ESS手術」のような臨床条件のみで再度ご入力ください。

---

## 💬 2. 対話的ヒアリング（/grill-me プロトコル）

医師からの初期入力が「疾患名や術式のみ」「ラフな箇条書きメモ」である場合、**いきなり完成版を作らず、まず以下の3〜4項目を簡潔に問いかけて臨床的ニュアンスを補正してください。**

1. **対象患者・同席者の想定**:
   - 例：高齢者本人向け、小児の保護者向け、ご家族同席、理解度に合わせた平易さのレベル
2. **術後経過や制限の具体的目安**:
   - 入院期間の目安（例：3泊4日）、安静期間、仕事や運動への復帰目安
3. **重点的に伝えたいリスク・合併症**:
   - 頻度の高い合併症（出血、疼痛、発熱など）や、頻度は低くても重要な重大合併症（神経麻痺、再手術など）
4. **病状説明のトーン**:
   - 落ち着いて安心感を与えるトーンか、あるいは再発リスクや注意点をストレートに伝えるトーンか

※ユーザーが「おまかせで」「標準的な内容で一気に作って」と指定した場合は、一般的な標準診療ガイドラインに基づき迅速にドラフト作成へ進んでください。

## 📋 3. 執筆ガイドライン（医療安全プロトコル）

生成する説明書は、以下の**標準構成**に従ってMarkdown形式で作成してください。

### 必須構成（セクション）
1. **はじめに（病名と現在の状態）**:
   - 医学用語には必ずわかりやすい日常の言葉を添える（例：「慢性副鼻腔炎（いわゆる蓄膿症）」）。
2. **治療（手術・処置）の目的と必要性**:
   - なぜこの手術が推奨されるのか、放置した場合のリスク。
3. **手術・処置の具体的な方法**:
   - 麻酔方法（全身麻酔・局所麻酔）、手術時間、切開部位や内視鏡の使い方を平易に。
4. **期待される効果と限界**:
   - 手術で治る部分と、完全には治らない可能性（症状緩和が目的など）。
5. **予想される合併症・偶発症**:
   - 発生頻度（よくある／まれ）、主な症状、起きた場合の病院側の対応策。
   - ※「100%安全」「絶対成功する」などの虚偽の保証は厳禁。
6. **術後の経過・入院スケジュール**:
   - 術当日から退院までの大まかなタイムライン。
7. **退院後の日常生活の注意点**:
   - 入浴、飲酒、運動、復職などの制限期間。
8. **緊急時の受診目安（レッドフラッグ）**:
   - 「こんな症状（激しい痛み、38度以上の発熱、止まらない出血）が出たらすぐに連絡してください」という明確な基準。
9. **他の治療法（代替療法）**:
   - 手術を行わない場合の保存的治療や経過観察の選択肢。
10. **医師の説明と患者・家族の確認欄**:
    - 説明日、説明医師名、患者署名欄、質問・同意チェックボックス。

## 🛠️ 4. Word文書（.docx）の自動生成手順

Markdownによる説明書ドラフトが完成したら、ユーザーがすぐに印刷・配布できるよう、同梱されているPythonスクリプトを実行してWord文書を生成します。

### 実行指示
Geminiのコード実行環境（Python）で、以下のコマンドを実行してください。

```python
import subprocess
import sys
from pathlib import Path

# 説明書本文（Markdown）を一時ファイルに保存
md_content = """<生成したMarkdown全文>"""

Path("document.md").write_text(md_content, encoding="utf-8")

# 同梱スクリプトを実行してWord (.docx) を生成
subprocess.run([sys.executable, "scripts/convert_to_docx.py", "document.md", "手術説明書.docx"], check=True)
```

### ユーザーへの提供
生成が完了したら、生成された `手術説明書.docx` のダウンロードリンクをチャット上に提示してください。
同時に、内容に修正点がないか医師にレビューを促してください。
