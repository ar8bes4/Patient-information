# 慢性副鼻腔炎（蓄膿症）の内視鏡手術（ESS）について

患者さんとご家族に、予定されている内視鏡下鼻副鼻腔手術（ESS）の内容、期待される効果、および起こりうる合併症について説明いたします。

## 1. ご病気と手術の目的
鼻の奥にある空洞（副鼻腔）に炎症が起き、膿がたまったり「鼻茸（ポリープ）」ができたりして、鼻づまりや嗅覚障害が続いています。
内服薬による治療を行いましたが改善が不十分なため、手術で鼻茸を切除し、副鼻腔の換気と排膿の通り道を広げます。

## 2. 起こりうる合併症・偶発症
手術は細心の注意を払って行いますが、解剖学的に眼や脳に近い部位を操作するため、以下の合併症が起こり得ます。

| 合併症の種類 | 発生頻度 | 主な症状と対応 |
| :--- | :--- | :--- |
| 術後出血 | 1〜2% 程度 | 鼻出血。止血ガーゼや内視鏡下での止血処置を行います。 |
| 眼窩内損傷 | まれ（0.1%未満） | 眼周囲の腫れ・複視。眼科と連携して治療します。 |
| 髄液漏 | 極めてまれ | 脳を包む膜の損傷による水様性鼻汁。発見次第、閉鎖処置を行います。 |

> [!WARNING]
> **退院後の緊急受診目安**
> 自宅に戻られた後、多量の鮮血が止まらない場合、または38度以上の高熱や激しい頭痛が続く場合は、夜間・休日を問わず直ちに当科外来または救急外来へご連絡ください。

## 3. 入院スケジュール
- **手術前日**: 入院、麻酔科受診、最終説明
- **手術当日**: 全身麻酔にて約2時間の手術
- **術後1〜2日**: 鼻内ガーゼの抜去、経過観察
- **術後3日目**: 退院予定
