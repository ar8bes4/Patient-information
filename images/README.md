# 患者説明文書用の図版

患者説明に用いるアイコン・イラストを管理します。図版は、患者さんに不安を与えにくい、簡潔で見やすい表現にします。

## 保存先

- `master/`: 作成直後の原版。作成指示や出典を添えて保存します。
- `optimized/`: Word文書・PDF・PowerPointに挿入する確認済み版。用途に合わせてサイズを調整します。

## 使用方法

Markdown原稿で、`src/` からの相対パスを使って画像を指定します。

```markdown
![図の説明](../images/optimized/図版ファイル名.png)
```

`convert_to_office.py` と `convert_to_pptx.py` は、この指定をWord文書とPowerPointへ反映します。

## 図版メモ

原版または確認済み版と同じ名前の `.md` ファイルに、次を記録します。

- 使用する説明書
- 図で伝える内容
- 作成指示または出典
- 医師確認者（未確認の場合は「未確認」）
- 確認日
