弛緩部型真珠腫（上鼓室型中耳真珠腫）に対する鼓室形成術の手術説明書

— 手術の目的・方法・合併症リスクと術後のセルフケアについて —

この説明書は、「弛緩部型真珠腫（しかんぶがた しんじゅしゅ）」と診断され、手術治療（鼓室形成術・乳突削開術）を予定されている患者さんとご家族に対し、病態、手術の必要性と方法、起こりうる合併症リスク、および術後の生活上の注意点について詳しくご説明するものです。

十分にご理解・ご納得いただいた上で、安心して治療をお受けいただけるよう、疑問やご不安な点がございましたらどのようなことでも担当医・医療スタッフへお尋ねください。

---

1. 病名と病態について

① 弛緩部型真珠腫（上鼓室型中耳真珠腫）とは

  • 真珠腫は「がん（悪性腫瘍）」ではありません。
  • 鼓膜の上部にある薄くてたるんだ部分（弛緩部：しかんぶ）が、中耳の奥（上鼓室・プルサク腔）へ向かって袋状に深く引き込まれる（陥凹する）ことから始まります。
  • その袋の中に、剥がれ落ちた皮膚の垢（角化物・角質）が外へ排出されずに溜まり、白く真珠のような塊（真珠腫）を形成する病気です。

② 放置することの危険性（周囲の骨を溶かす性質）

真珠腫の最大の特徴は、周囲の骨を少しずつ溶かし（骨破壊）ながら、奥深くへ拡大していく性質があることです。

  • 音を伝える骨（耳小骨）の破壊: 音を伝える3つの小さな骨（ツチ骨・キヌタ骨・アブミ骨）が壊され、聞こえが悪くなります（伝音難聴＝音を奥へ届ける仕組みの障害）。
  • 悪臭を伴う耳だれ（耳漏）: 溜まった垢に細菌が繁殖し、点耳薬や飲み薬を使っても治りにくい耳だれを繰り返します。
  • 重要な周囲器官・神経への波及:
  • 顔面神経麻痺: 顔の表情を作る神経の骨が溶けると、顔の半分が動かなくなります（目が閉じない、口角が下がる）。
  • 激しいめまい・高度難聴（内耳炎・外側半規管瘻孔）: 平衡感覚を感じる三半規管や音を感じる蝸牛の骨が溶けると、激しい回転性めまいが生じ、音を感じる神経が傷ついて治らない難聴（感音難聴）になる恐れがあります。
  • 頭蓋内合併症（髄膜炎・脳膿瘍）: 脳との境目の骨が溶けると、生命に関わる重篤な頭蓋内感染症を引き起こす危険があります。

!NOTE

飲み薬や点耳薬、外来での清掃だけでは骨を溶かす進行を止めることができません。病変を完全に取り除き、危険な合併症を防ぐためには手術が唯一の根本的治療法です。

---

2. 予定される手術と目的

  • 予定手術名: 鼓室形成術（こしつけいせいじゅつ） / 乳突削開術（にゅうとつさっかいじゅつ）
  • 麻酔方法: 通常、全身麻酔で行われます（手術中は完全に眠っており、痛みを感じることはありません）。

手術の4つの目的（優先順位）

1. 真珠腫病巣の完全摘出（最優先）:

骨を溶かして広がる病変を完全に取り除き、病気の進行を止め、危険な合併症を防ぎます。

2. 安全で清潔な耳の構造の再建:

耳だれが止まり、外からの感染を起こしにくい健全な中耳・外耳道形態を作ります。

3. 鼓膜および骨壁の補強・再建（再発予防）:

再建した鼓膜が再び奥に凹んで新しい真珠腫ができるのを防ぐため、患者さんご自身の軟骨や筋膜で骨の壁（上鼓室側壁）を頑丈に補強します。

4. 聴力の改善・維持（音を伝える仕組みの再建）:

破壊された耳小骨の連鎖を、ご自身の骨や軟骨、または人工耳小骨を用いて再建します。

!IMPORTANT

【最優先事項について】 本手術の最優先目的は「真珠腫の完全除去と重篤な合併症の防止」です。聴力改善は重要な目的ですが、病変の広がりや感染の強さによっては、聴力改善が得られない場合や、安全のため聴力再建を後日の手術に分ける（二期的手術）場合があります。

---

3. 手術の方法と術式

患者さんの真珠腫の広がり具合、骨破壊の程度、耳の骨の構造に応じて、最も安全で再発しにくい術式を選択します。

① 手術の具体的な手順

1. 切開: 耳の後ろの皮膚（または耳の穴の入り口付近）を切開します。

2. 骨の削開（乳突削開）: 顕微鏡や耳科用内視鏡を用い、耳の後ろの骨（蜂の巣状の乳突部）や上鼓室の骨を専用のドリルで慎重に削り、真珠腫の全貌を露出します。

3. 病変の完全剥離・摘出: 大切な顔面神経や内耳、脳を包む硬膜を傷つけないよう慎重に剥離し、真珠腫の袋（母膜）を残さず摘出します。

  • ※耳小骨の意図的切除について: 真珠腫を奥深くまで残さず安全に摘出するため、病変に巻き込まれた音を伝える骨（キヌタ骨やツチ骨頭）をあえて切除・摘出（離断）することがあります。

4. 骨壁・鼓膜の再建: 患者さんご自身の耳介軟骨や側頭筋膜を採取し、溶けた上鼓室側壁を再建して将来の再陥凹を防ぎ、鼓膜を修復します。

5. 聴力再建（耳小骨形成術）: 残ったアブミ骨などの状態に合わせて、自家骨や人工耳小骨（TORP/PORP）を配置して音の伝導路を再建します。

6. 保護とパッキング: 再建した鼓膜や耳小骨がずれないよう、耳の中に保護用のスポンジやガーゼ（パッキング）をしっかり詰めて手術を終了します。

② 術中判断による術式変更・二期的手術への切り替えについて

!WARNING

### ⚠️ 術中判断による術式・計画変更の承諾について 術前の画像検査（CT等）では判別できない微小な病変の進展、内耳や顔面神経との強固な癒着、外側半規管瘻孔の存在が手術中に初めて判明することがあります。 この場合、患者さんの生命と機能の安全（失聴や顔面麻痺の防止）を最優先とし、執刀医の判断で予定していた術式を変更したり、聴力再建を中止して病巣除去のみを行い、約1年後に改めて再発確認と聴力再建を行う「二期的手術（段階的手術）」に切り替えることがあります。あらかじめご了承ください。

---

4. 手術に伴う主なリスク・合併症（インフォームド・コンセント）

手術にあたっては、神経刺激モニター等の精密機器を用いて細心の注意を払いますが、解剖学的な近接性から以下のような合併症のリスクがあります。

① 聴覚および内耳に関するリスク

!IMPORTANT

### 📢 術直後の一時的な聴力低下について（必ずお読みください） 手術直後から耳の中の詰め物を完全に除去するまでの術後数週間〜約1ヶ月間は、耳の中に保護用スポンジやガーゼが入っているため、術前よりも一時的に聞こえが悪くなります（水の中にいるような強い詰まり感）。 これは正常な治癒過程であり、詰め物を除去し中耳の粘膜が落ち着く（術後1〜3ヶ月）につれて本来の聴力改善が得られていきますので、ご安心ください。

  • 不可逆的な感音難聴・失聴（極めて稀ですが重要）:

真珠腫が内耳（三半規管や蝸牛）に食い込んでいた場合（半規管瘻孔）や、病変剥離時の内耳刺激、ドリルの振動等により、音を感じる神経が傷つき、治療しても元に戻らない高度感音難聴や失聴（完全に聞こえなくなること）に至るリスクがあります（発生頻度：約1〜2%）。

  • めまい・ふらつき: 内耳への刺激により、術後数日〜数週間にわたり回転性めまいが生じることがあります（通常はお薬で徐々に軽快します）。
  • 耳鳴り・耳閉感: 術後に耳鳴りが新しく出現したり、一時的に強くなることがあります。

② 神経に関するリスク

  • 顔面神経麻痺（顔の表情の麻痺）:

顔の筋肉を動かす神経は中耳のすぐそばを通っています。真珠腫による骨破壊や剥離操作の影響で、術後に顔の半分が動かしにくくなるリスクがあります（発生頻度：1%未満）。神経モニターを用いて最大限保護しますが、重度の癒着例等では麻痺が完全には回復せず、後遺症（顔の歪み、目の閉じにくさ）が残る可能性があります。

  • 味覚障害（舌のしびれ・金属味）:

中耳を通る味覚神経（鼓索神経）が病変に巻き込まれている場合、病巣完全摘出のために神経を意図的に切断または牽引せざるを得ないことがあります。この場合、術後に舌の同側（前2/3）の味覚低下、しびれ、金属のような異味感が生じます。多くは数ヶ月〜1年程度で代償され気にならなくなりますが、症状が長期または永続的に残る可能性があります。

③ 再発・遺残のリスク

真珠腫の手術において再発リスクは一定割合（約10〜20%程度）で不可避的に存在します。

  • 遺残性再発: 顕微鏡でも見えない微小な細胞が残り、数年かけて再び育つもの（術後3年以内に好発）。
  • 再形成性再発: 手術で治した鼓膜が、耳管機能不全や鼻すすり等の陰圧によって再び奥へ引き込まれ、新しい真珠腫を作ってしまうもの（術後3年以上経過しても発生）。
  • ※再発が確認された場合は、外来処置や再手術が必要になります。

④ その他の一般的リスク

  • 出血・創部感染・血腫: 止血処置や抗生物質投与で対応します。
  • 鼓膜再穿孔・再建骨の偏位: 移植した鼓膜が生着しなかったり、人工耳小骨の位置がずれて再建手術が必要になることがあります。
  • 頭蓋内合併症（極めて稀）: 天蓋骨破壊に伴う髄液漏や髄膜炎（適切な閉鎖処置・抗生剤で管理します）。
  • 機器熱傷・外耳道熱損傷: ドリルや内視鏡による熱影響を最小限に抑えるため、十分な冷却洗浄を行いながら施行します。

5. 入院から普段の生活に戻るまでのスケジュール

患者さんとご家族が療養生活を見通せるよう、標準的なロードマップをまとめました。

| 時期 | 状態・処置 | 日常生活・活動のめやす |

| :--- | :--- | :--- |

| 手術当日 | 全身麻酔・術後ベッド上安静 | 傷の痛みは点滴や内服の痛み止めでしっかりコントロールします |

| 術後1〜2日目 | 歩行開始・診察・点滴 | 首から下のシャワー浴が可能になります |

| 術後5〜7日目 | 退院（創部確認） | デスクワークや軽作業、学校の通常授業への復帰が可能です |

| 術後1〜2週目 | 外来通院（抜糸・処置） | 耳の詰め物の状態確認、創部の抜糸を行います |

| 術後3〜4週目 | 耳の詰め物完全抜去 | 耳の詰め物が取れ、聞こえの回復を実感し始めます |

| 術後1ヶ月以降 | 運動・入浴の制限解除 | 体を使う重労働、体育・激しいスポーツ、長湯・サウナの再開 |

| 術後1〜3ヶ月 | 聴力検査・経過観察 | 鼓膜と中耳粘膜が安定し、最終的な聴力評価を行います |

6. 【最重要】ご自宅でのセルフケアと厳禁事項

手術の成功と再発防止には、患者さんご自身のセルフケアが極めて重要です。

🚨 1. 「鼻すすり」は絶対に禁止です！

鼻を「ズズッ」とすすると、ストローで吸い上げたときのように中耳の中に強い陰圧（引っ張る力）がかかります。

これにより、綺麗に作り直した鼓膜や軟骨が奥へ引きずり込まれ、真珠腫が再発（再形成）する最大の原因になります。

  • 💡 鼻水が出たとき: すするのではなく、ティッシュでそっと押さえて拭き取るか、片方ずつ優しくかんでください。
  • 💡 くしゃみが出そうなとき: 口を手で塞がず、口を開けてくしゃみをすると耳に圧力が逃げます。
  • 💡 アレルギー性鼻炎・花粉症がある方: 鼻水が出やすい時期は我慢せず医師に相談し、お薬（抗アレルギー薬や点鼻薬）で鼻炎をしっかりコントロールしましょう。

🚿 2. 耳に水が入らない工夫（洗髪・シャワー手順）

耳の中に詰め物がある間や、医師の許可が出るまでは、耳の中に絶対に水が入らないようにしてください。

  • 防水手順:

1. 耳の穴の入り口に、ワセリンを薄く塗った脱脂綿（コットン）を軽く詰めます。

2. その上から市販のイヤーキャップ（またはラップ）をかぶせ、テープで固定します。

3. 洗髪後は速やかに周囲の水分をタオルで拭き取り、コットンを外してください。

✈️ 3. その他の注意事項

  • 術後1ヶ月間控えること: 重い荷物を持つ力仕事、激しいスポーツ、サウナ・長風呂、飛行機への搭乗、水泳・潜水など。
  • 長期定期通院の継続: 真珠腫は数年〜10年単位で再発することがあります。耳の状態維持と再発早期発見のため、指示された定期診察（耳内視鏡・CT/MRI検査）を必ず継続してください。

7. よくあるご質問 (Q&A)

  • Q. 手術後、すぐに聞こえは良くなりますか？
  • A. 手術直後は耳の中に保護用の詰め物や浸出液が入っているため、一時的に術前より聞こえが悪くなります。詰め物が取れ、粘膜が落ち着く術後1〜3ヶ月頃から徐々に聴力の改善を実感できるようになります。
  • Q. 痛みは我慢しなければなりませんか？
  • A. 我慢する必要は全くありません。術後の傷の痛みに対しては、効果的な鎮痛薬（内服薬・坐薬・点滴）を適切に使用して痛みをコントロールしますので、遠慮なくスタッフにお伝えください。

8. 要約（重要ポイントのまとめ）

| 項目 | 説明内容 |

| :--- | :--- |

| 病名 | 弛緩部型真珠腫（上鼓室型中耳真珠腫）（骨を溶かしながら進行する病態） |

| 手術名 | 鼓室形成術 ＋ 乳突削開術（全身麻酔） |

| 手術の目的 | ① 病巣の完全摘出（最優先） ② 合併症予防 ③ 鼓膜・骨壁再建 ④ 聴力再建 |

| 術中変更・段階手術 | 安全性最優先のため、術中判断で術式変更や二期的手術（約1年後）への切り替えあり |

| 術直後の聴力 | 耳の詰め物により術直後は一時的に聞こえが悪くなります（正常な経過） |

| 主な合併症リスク | 聴力低下（感音難聴・失聴リスク1〜2%）、めまい、顔面神経麻痺、味覚障害、再発 |

| 術後の最重要ルール | 「鼻すすり絶対禁止」、優しくかむ、水濡れ厳禁（イヤーキャップ）、長期定期通院 |

【医療スタッフ用メモ（インフォームド・コンセント確認項目）】

  • 術前画像評価の確認:

1. 上鼓室側壁（Scutum）の骨破壊範囲、乳突蜂巣への進展度

2. 耳小骨連鎖の破壊状態（ツチ・キヌタ関節離断、アブミ骨上構造の残存有無、アブミ骨意図的切除の必要性）

3. 外側半規管瘻孔の有無（術前めまい症状・Fistula signの有無）

4. 顔面神経管の骨欠損・露出の有無、硬膜露出・天蓋骨破壊の有無

  • 術前説明と方針共有:
  • 一期的聴力再建（PORP/TORP/自家骨）か二期的手術（second-look operation）への切り替え裁量権の説明。
  • 術直後のパッキング遮音による一時的難聴の予告。
  • 鼓索神経切断時の味覚障害、外側半規管瘻孔時の不可逆的感音難聴リスクの告知。
  • 術後の耳管機能不全および鼻すすり習慣の是正指導の徹底。
